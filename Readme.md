# StepAcademy — Online Coding Homework

Welcome to my homework repository for the **StepAcademy Online Coding** program.

This repository contains coding exercises, practice projects, and other assignments completed throughout the course. Each assignment is organized in its own folder and may include source code, supporting files, and instructions specific to that task.

## Repository Structure

```text
StepAcademy/
├── homework-01/
├── homework-02/
└── ...
```

## Working With the Assignments

1. Open the folder for the assignment you want to review.
2. Read any assignment-specific instructions.
3. Follow the setup and run commands included in that folder.

## Purpose

The goal of this repository is to document my progress, practice programming concepts, and keep all StepAcademy homework assignments in one place.
